# 🌍 TVRS Maps - Jeu de Géographie 3D

Une expérience interactive et immersive pour tester vos connaissances géographiques. Devinez les pays et les capitales du monde entier sur un globe 3D dynamique.

**Jouez ici : [maps.tvrs.fr](https://maps.tvrs.fr)**

## ✨ Fonctionnalités

*   **Globe 3D Interactif :** Visualisation fluide avec `react-globe.gl` et `Three.js`.
*   **Deux Modes de Jeu :**
    *   **Pays :** Identifiez les pays à partir de leur emplacement ou de leur nom.
    *   **Capitales :** Trouvez la capitale associée au pays mis en avant.
*   **Contrôle Vocal :** Jouez sans les mains grâce à l'intégration de l'API de reconnaissance vocale.
*   **Design Moderne :** Interface épurée avec effet *Glassmorphism*, support des modes **Sombre/Clair** et vue **Satellite**.
*   **Statistiques en Temps Réel :** Suivez votre progression par continent.
*   **Optimisé Mobile :** Expérience fluide sur smartphones avec gestion intelligente du clavier et du zoom tactile.

## 🚀 Installation Locale

1.  **Cloner le dépôt :**
    ```bash
    git clone https://github.com/VOTRE_NOM/tvrs-maps.git
    cd tvrs-maps
    ```

2.  **Installer les dépendances :**
    ```bash
    npm install
    ```

3.  **Lancer le projet :**
    ```bash
    npm run dev
    ```

    Pour lancer le serveur local sur le port 5001 :
    ```bash
    npm run dev:5001
    ```

## 🛠️ Stack Technique

*   **Framework :** React 19
*   **Visualisation :** React-Globe.gl, Three.js
*   **Icônes :** Lucide React
*   **Build Tool :** Vite
*   **Déploiement :** Vercel
